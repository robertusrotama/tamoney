Kode ditulis dengan gaya **Ponytail** (skill di `.claude/skills/ponytail/`): perubahan terkecil yang lengkap, pakai yang sudah ada, tanpa abstraksi "untuk nanti".

**Why:** Diminta user 2026-10-29.

**How to apply:** Jangan memotong validasi, error handling, keamanan, atau aksesibilitas. Logika non-trivial tetap punya test.
